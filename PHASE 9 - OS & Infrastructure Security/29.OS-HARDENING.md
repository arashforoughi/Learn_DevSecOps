## 29.1 CIS Benchmarks Overview

### What is CIS?

CIS (Center for Internet Security) Benchmarks provide:

- Best practices for OS hardening
- Consensus-driven recommendations
- Evaluated against major threats
- Compliance framework (PCI-DSS, HIPAA, SOC2)
- Improves security baseline

### CIS Ubuntu 22.04 Checklist

```
Initial Setup:
✅ Disable unnecessary filesystems
✅ Configure /tmp, /var/tmp, /var/log permissions
✅ Bind mount /var/tmp to /tmp

Access Control:
✅ World-writable files audit
✅ SUID/SGID binaries audit
✅ Proper umask settings (0077)

System Accounting:
✅ auditd enabled
✅ Audit rules for system calls
✅ Centralized log collection
```

## 29.2 Kernel Hardening

### Sysctl Parameters

```bash
cat > /etc/sysctl.d/99-hardening.conf << 'EOF'
# Kernel protection
kernel.kptr_restrict = 2
kernel.dmesg_restrict = 1
kernel.unprivileged_bpf_disabled = 1
kernel.unprivileged_userns_clone = 0

# ASLR (Address Space Layout Randomization)
kernel.randomize_va_space = 2

# Panic on oops
kernel.panic_on_oops = 1
kernel.panic = 60

# Protect against SYN floods
net.ipv4.tcp_syncookies = 1

# Enable reverse path filtering
net.ipv4.conf.all.rp_filter = 1
EOF

sysctl -p /etc/sysctl.d/99-hardening.conf
```

## 29.3 Seccomp (Syscall Filtering)

Block dangerous syscalls in Kubernetes:

```yaml
apiVersion: v1
kind: Pod
metadata:
  name: hardened-pod
spec:
  securityContext:
    seccompProfile:
      type: RuntimeDefault
  containers:
  - name: app
    image: myapp:latest
    securityContext:
      allowPrivilegeEscalation: false
      readOnlyRootFilesystem: true
      runAsNonRoot: true
      runAsUser: 1000
      capabilities:
        drop:
        - ALL
```

## 29.4 AppArmor Profiles

```bash
# Apply AppArmor profile
aa-status

# Create custom profile
cat > /etc/apparmor.d/containers/kubernetes << 'EOF'
#include <tunables/global>

profile kubernetes-default flags=(attach_disconnected) {
  #include <abstractions/base>
  #include <abstractions/nameservice>

  network,
  capability,
  file,
  mount,
}
EOF

apparmor_parser -r /etc/apparmor.d/containers/kubernetes
```

## 29.5 File Integrity Monitoring

```bash
# Install AIDE
apt-get install -y aide aide-common

# Initialize baseline
aideinit && cp /var/lib/aide/aide.db.new /var/lib/aide/aide.db

# Check for changes
aide --check

# Schedule daily checks
0 2 * * * /usr/sbin/aide --check > /var/log/aide-check.log
```

## 29.6 Audit Logging

```bash
# Enable and configure auditd
systemctl enable auditd

# Monitor critical files
auditctl -w /etc/passwd -p wa -k passwd_changes
auditctl -w /etc/group -p wa -k group_changes
auditctl -w /etc/sudoers -p wa -k sudoers_changes

# View logs
ausearch -k passwd_changes
```
