## 🎯 **COMPLETE PIPELINE VISUALIZATION**

```
Developer writes code
    ↓
Git commit & push
    ↓
GitLab triggers CI/CD
    ├─ Build ────────────────────────────────┐
    ├─ Test (code coverage)                  │
    ├─ SonarQube SAST scan                   │
    ├─ Quality gate (must pass)              │
    └─ Code review (merge approval)          │
         ↓                                     │
    Build Docker image  ←─────────────────────┘
         ↓
    Push to Harbor
         ↓
    Harbor scans image (Trivy)
         ↓
    DefectDojo imports findings
         ↓
    Manual approval gate
         ↓
    Image signed + attested
         ↓
    SBOM generated & published
         ↓
    Compliance check (SLA, policies)
         ↓
    Ready for deployment ✅
         ↓
    Kubernetes pulls image (via Teleport)
         ↓
    Secrets retrieved from Vault
         ↓
    Certificates from Vault PKI
         ↓
    Access logged in Teleport
         ↓
    Complete audit trail recorded
```
