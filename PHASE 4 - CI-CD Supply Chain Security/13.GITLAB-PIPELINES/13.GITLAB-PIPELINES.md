## 13.1 Why GitLab Matters in DevSecOps

GitLab is the **single source of truth** for:

- **Code:** All source code version-controlled
- **CI/CD:** Automated testing and building
- **Security:** Integration with security tools (SAST, DAST, container scanning)
- **Collaboration:** Code review before merge
- **Audit:** Every commit, review, deploy is logged

🏗️ **Analogy:** GitLab is like a modern factory:

- **Source code = raw materials** (stored in repository)
- **Merge requests = quality control** (review before production)
- **CI/CD pipelines = assembly line** (automated build, test, scan)
- **Container registry = warehouse** (store finished products)
- **Deployments = shipping** (deploy to production)

## 13.2 Installation (Docker Compose)

Log into `sec-vcs-01`:

```bash
$ ssh sec-vcs-01
```

### Step 1 — Create GitLab Directory

```bash
vm# mkdir -p /opt/gitlab/{config,logs,data}
vm# cd /opt/gitlab
```

### Step 2 — Create docker-compose.yml

```bash
vm# cat > /opt/gitlab/docker-compose.yml << 'EOF'
version: '3.8'

services:
  gitlab:
    image: gitlab/gitlab-ce:latest
    container_name: gitlab
    restart: always
    hostname: gitlab.devsecops.com
    
    environment:
      GITLAB_OMNIBUS_CONFIG: |
        # Core GitLab settings
        external_url 'https://gitlab.devsecops.com'
        gitlab_rails['time_zone'] = 'UTC'
        
        # Database (using PostgreSQL)
        postgresql['enable'] = false
        gitlab_rails['db_adapter'] = 'postgresql'
        gitlab_rails['db_encoding'] = 'utf8'
        gitlab_rails['db_database'] = 'gitlabdb'
        gitlab_rails['db_username'] = 'gitlab'
        gitlab_rails['db_password'] = 'gitlab_db_password'
        gitlab_rails['db_host'] = 'postgres'
        gitlab_rails['db_port'] = 5432
        
        # Redis
        redis['enable'] = false
        gitlab_rails['redis_host'] = 'redis'
        gitlab_rails['redis_port'] = 6379
        
        # OIDC authentication (Authentik)
        gitlab_rails['omniauth_enabled'] = true
        gitlab_rails['omniauth_allow_single_sign_on'] = ['oidc']
        gitlab_rails['omniauth_block_auto_created_users'] = false
        
        gitlab_rails['omniauth_providers'] = [
          {
            "name" => "oidc",
            "label" => "Authentik",
            "args" => {
              "name" => "oidc",
              "scope" => ["openid", "profile", "email"],
              "response_type" => "code",
              "issuer" => "http://sec-idm-01:9000/application/o/gitlab/",
              "client_auth_method" => "query",
              "discovery" => true,
              "uid_field" => "email",
              "client_options" => {
                "identifier" => "gitlab-oidc-client-id",
                "secret" => "gitlab-oidc-client-secret",
                "redirect_uri" => "https://gitlab.devsecops.com/users/auth/oidc/callback"
              }
            }
          }
        ]
        
        # Nginx (disable, use external HAProxy)
        nginx['enable'] = false
        
        # SSH
        gitlab_rails['gitlab_shell_ssh_port'] = 22
        
        # Monitoring (disable for lab)
        prometheus_monitoring['enable'] = false
        
        # Container registry
        registry['enable'] = false  # Use external Harbor instead
        
        # Backup location
        gitlab_rails['backup_path'] = '/var/opt/gitlab/backups'
        gitlab_rails['backup_keep_time'] = 604800  # 7 days

    ports:
      - "22:22"
      - "80:80"
      - "443:443"
    
    volumes:
      - ./config:/etc/gitlab
      - ./logs:/var/log/gitlab
      - ./data:/var/opt/gitlab
    
    depends_on:
      - postgres
      - redis
    
    networks:
      - devsecops

  postgres:
    image: postgres:14
    container_name: gitlab-postgres
    restart: always
    
    environment:
      POSTGRES_DB: gitlabdb
      POSTGRES_USER: gitlab
      POSTGRES_PASSWORD: gitlab_db_password
      POSTGRES_INITDB_ARGS: "--encoding=UTF8 --locale=C"
    
    volumes:
      - ./postgres_data:/var/lib/postgresql/data
    
    networks:
      - devsecops

  redis:
    image: redis:7-alpine
    container_name: gitlab-redis
    restart: always
    command: redis-server --appendonly yes
    
    volumes:
      - ./redis_data:/data
    
    networks:
      - devsecops

networks:
  devsecops:
    driver: bridge

EOF
```

### Step 3 — Start GitLab

```bash
vm# docker-compose up -d
vm# docker-compose logs -f gitlab  # Wait for startup (2-3 minutes)
```

Watch for: `gitlab Reconfigured GitLab and found errors above? Please check the output above.`

### Step 4 — Get Initial Root Password

```bash
vm# docker exec -it gitlab grep "Password:" /etc/gitlab/initial_root_password
```


### Step 5 — Configure in HAProxy

Update HAProxy to route to GitLab:

```bash
$ ssh sec-edge-01 'sudo tee -a /etc/haproxy/haproxy.cfg' << 'EOF'

    server gitlab-01 10.0.2.14:80 check

use_backend be_gitlab if host_gitlab

EOF

$ ssh sec-edge-01 'sudo systemctl reload haproxy'
```

## 13.4 Configure OIDC Authentication

### Step 1 — Create OIDC App in Authentik

In Authentik Admin Console:

1. **Applications → Create Application**
    
    - Name: GitLab
    - Slug: gitlab
    - Provider: OAuth2/OIDC (new)
2. **OAuth2 Provider:**
    
    - Client ID: `gitlab-oidc-client-id` (must match docker-compose)
    - Client Secret: `gitlab-oidc-client-secret`
    - Redirect URIs: `https://gitlab.devsecops.com/users/auth/oidc/callback`
    - Scopes: openid, profile, email

### Step 2 — Update GitLab Configuration

```bash
vm# docker exec gitlab vi /etc/gitlab/gitlab.rb
# Update client_id and client_secret to match Authentik

vm# docker exec gitlab gitlab-ctl reconfigure
```

### Step 3 — Test OIDC Login

- Logout from GitLab
- Click "Authentik" button
- Login with LDAP credentials (john, alice, bob)
- Should be redirected back to GitLab

## 13.5 Create Projects & Repositories

### Create Application Project

```bash
# As root in GitLab UI:
# New Project → Create Blank Project

Name: myapp
Description: Sample Application for CI/CD
Visibility: Private  # (or Internal)
```

### Initialize Git Repository

On your host:

```bash
# Clone the empty project
$ git clone https://gitlab.devsecops.com/root/myapp.git
$ cd myapp

# Create sample application
$ cat > app.py << 'EOF'
#!/usr/bin/env python3
"""
Simple Flask application for CI/CD demo
"""
from flask import Flask, jsonify

app = Flask(__name__)

@app.route('/health')
def health():
    return jsonify({"status": "healthy", "version": "1.0.0"}), 200

@app.route('/api/message')
def message():
    return jsonify({"message": "Hello from DevSecOps Lab!"}), 200

if __name__ == '__main__':
    app.run(host='0.0.0.0', port=5000, debug=False)

EOF

# Create requirements.txt
$ cat > requirements.txt << 'EOF'
Flask==2.3.0
gunicorn==20.1.0

EOF

# Create Dockerfile
$ cat > Dockerfile << 'EOF'
FROM python:3.11-slim

WORKDIR /app

COPY requirements.txt .
RUN pip install -r requirements.txt

COPY app.py .

EXPOSE 5000

CMD ["gunicorn", "--bind", "0.0.0.0:5000", "app:app"]

EOF

# Create CI/CD pipeline
$ cat > .gitlab-ci.yml << 'EOF'
stages:
  - build
  - test
  - scan
  - package

variables:
  REGISTRY_URL: harbor.devsecops.com
  DOCKER_HOST: tcp://docker:2375
  DOCKER_TLS_VERIFY: ""

# Build stage
build:
  stage: build
  image: python:3.11-slim
  script:
    - pip install -r requirements.txt
    - echo "Build successful"
  artifacts:
    paths:
      - requirements.txt
    expire_in: 1 hour

# Test stage
test:
  stage: test
  image: python:3.11-slim
  script:
    - pip install -r requirements.txt
    - pip install pytest pytest-cov
    - pytest tests/ --cov=. --cov-report=xml
  coverage: '/TOTAL.*\s+(\d+%)$/'
  artifacts:
    reports:
      coverage_report:
        coverage_format: cobertura
        path: coverage.xml
  only:
    - merge_requests

# SonarQube scan
sonarqube:
  stage: scan
  image: sonarsource/sonar-scanner-cli:latest
  script:
    - sonar-scanner
      -Dsonar.projectKey=myapp
      -Dsonar.sources=.
      -Dsonar.host.url=https://sonarqube.devsecops.com
      -Dsonar.login=$SONARQUBE_TOKEN
  only:
    - merge_requests

# Build Docker image
docker_build:
  stage: package
  image: docker:20.10
  services:
    - docker:20.10-dind
  script:
    - docker login -u $HARBOR_USERNAME -p $HARBOR_PASSWORD $REGISTRY_URL
    - docker build -t $REGISTRY_URL/myapp:$CI_COMMIT_SHA .
    - docker push $REGISTRY_URL/myapp:$CI_COMMIT_SHA
    - docker tag $REGISTRY_URL/myapp:$CI_COMMIT_SHA $REGISTRY_URL/myapp:latest
    - docker push $REGISTRY_URL/myapp:latest
  only:
    - main
    - master

EOF

# Create test directory
$ mkdir tests
$ cat > tests/test_app.py << 'EOF'
import pytest
from app import app

@pytest.fixture
def client():
    app.config['TESTING'] = True
    with app.test_client() as client:
        yield client

def test_health(client):
    response = client.get('/health')
    assert response.status_code == 200
    assert response.json['status'] == 'healthy'

def test_message(client):
    response = client.get('/api/message')
    assert response.status_code == 200
    assert 'message' in response.json

EOF

# Commit and push
$ git add .
$ git commit -m "Initial application setup with CI/CD"
$ git push origin main

```

## 13.6 CI/CD Pipeline Configuration

### Step 1 — Set CI/CD Variables

In GitLab UI:

- Project → Settings → CI/CD → Variables

Add:

- `HARBOR_USERNAME`: your Harbor username
- `HARBOR_PASSWORD`: your Harbor password (or use Vault token)
- `SONARQUBE_TOKEN`: SonarQube token

### Step 2 — Integrate with Vault

Update `.gitlab-ci.yml` to fetch secrets from Vault:

```yaml
# Fetch database password from Vault
before_script:
  - |
    export DB_PASSWORD=$(curl -s \
      -H "X-Vault-Token: $VAULT_TOKEN" \
      https://vault.devsecops.com/v1/secret/data/database/mysql | \
      jq -r '.data.data.password')
```

### Step 3 — Enable Docker-in-Docker (for container building)

```bash
vm# docker exec gitlab gitlab-rails runner '
  Gitlab::CurrentSettings.update_columns(
    shared_runners_enabled: true,
    runners_registration_token_reset_interval: 0
  )
'
```

## 13.8 Webhooks to Trigger Deployments

Configure GitLab to trigger deployments on merge:

```bash
# In GitLab:
# Project → Settings → Webhooks

Add webhook:
- URL: https://deployment-system.devsecops.com/deploy
- Trigger: Merge request events, Push events
- SSL verification: enable (if cert is valid)

# Example webhook handler (on deployment system):
@app.route('/deploy', methods=['POST'])
def deploy():
    data = request.json
    if data['event_type'] == 'push':
        # Trigger deployment pipeline
        deploy_image(data['project'], data['ref'], data['commit_sha'])
    return {'status': 'ok'}, 202
```

## 13.9 Backup & Restore

### Create Backup

```bash
vm# docker exec gitlab gitlab-backup create SKIP=registry
```

Backups are stored in `/opt/gitlab/data/backups/`

### Restore from Backup

```bash
vm# docker-compose down
vm# docker-compose up -d postgres redis
vm# sleep 10  # Wait for DB to initialize

vm# docker exec gitlab gitlab-backup restore BACKUP=<backup_filename>
vm# docker exec gitlab gitlab-ctl reconfigure
vm# docker-compose restart gitlab
```

## 13.10 Security Best Practices

### 1. Enable Branch Protection

```bash
# In GitLab:
# Project → Settings → Repository → Branch Protection

main branch:
  - Require code review before merge (1+ approvers)
  - Dismiss stale approvals
  - Require all discussions resolved
  - Require CI/CD pipeline to succeed
```

### 2. Configure Audit Logging

```bash
vm# docker exec gitlab gitlab-rails runner '
  PersonalAccessToken.where(active: true).each do |token|
    token.update(scopes: [:api])  # Limit scopes
  end
'
```

### 3. Enable HTTPS Only

Already configured via HAProxy (TLS termination).

### 4. Enforce Signed Commits

```bash
# In GitLab:
# Project → Settings → Repository → Require signed commits
```

## 13.12 Validation Script — Chapter 13

```bash
#!/bin/bash
# ~/lab/scripts/validate-chapter-13.sh

set -euo pipefail

GITLAB_IP="10.0.2.14"
GITLAB_URL="https://$GITLAB_IP"
PASS=0
FAIL=0

echo "============================================="
echo " Chapter 13 Validation — GitLab CE          "
echo "============================================="

echo ""
echo "--- GitLab Docker Service ---"

if ssh sec-vcs-01 'docker ps | grep -q gitlab' 2>/dev/null; then
    echo "  ✅ PASS: GitLab container is running"
    ((PASS++))
else
    echo "  ❌ FAIL: GitLab container not running"
    ((FAIL++))
fi

echo ""
echo "--- Web UI Access ---"

if curl -s -k $GITLAB_URL/ 2>/dev/null | grep -q "GitLab"; then
    echo "  ✅ PASS: GitLab web UI is accessible"
    ((PASS++))
else
    echo "  ❌ FAIL: GitLab web UI not responding"
    ((FAIL++))
fi

echo ""
echo "--- PostgreSQL Database ---"

if ssh sec-vcs-01 'docker ps | grep -q gitlab-postgres' 2>/dev/null; then
    echo "  ✅ PASS: PostgreSQL is running"
    ((PASS++))
else
    echo "  ❌ FAIL: PostgreSQL not running"
    ((FAIL++))
fi

echo ""
echo "--- Redis Cache ---"

if ssh sec-vcs-01 'docker ps | grep -q gitlab-redis' 2>/dev/null; then
    echo "  ✅ PASS: Redis is running"
    ((PASS++))
else
    echo "  ❌ FAIL: Redis not running"
    ((FAIL++))
fi

echo ""
echo "--- Results ---"
echo "  Passed: ${PASS}"
echo "  Failed: ${FAIL}"

if [ "$FAIL" -eq 0 ]; then
    echo ""
    echo "🎉 GitLab is operational!"
    echo "   Access: https://gitlab.devsecops.com"
else
    echo ""
    echo "⚠️  ${FAIL} check(s) failed."
    exit 1
fi

```
