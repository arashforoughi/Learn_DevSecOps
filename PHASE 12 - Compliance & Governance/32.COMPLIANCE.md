## 32.2 SOC2 Type II Implementation

### SOC2 Control Categories

```bash
#!/bin/bash
# soc2-evidence-collection.sh

REPORT_DIR="/compliance/soc2/$(date +%Y-%m)"
mkdir -p "$REPORT_DIR"

# CC7: Access Control Evidence
echo "=== CC7.1 User Access Restriction ===" > "$REPORT_DIR/cc7-access-control.txt"
kubectl get clusterrolebindings >> "$REPORT_DIR/cc7-access-control.txt"
kubectl get rolebindings -A >> "$REPORT_DIR/cc7-access-control.txt"
cat /etc/sudoers >> "$REPORT_DIR/cc7-access-control.txt"

# CC7.2 System Monitoring
echo "=== CC7.2 System Monitoring ===" > "$REPORT_DIR/cc7-monitoring.txt"
systemctl status auditd >> "$REPORT_DIR/cc7-monitoring.txt"
auditctl -l | wc -l >> "$REPORT_DIR/cc7-monitoring.txt"
prometheus_querycount=$(curl -s "http://prometheus:9090/api/v1/query?query=up" | jq '.data.result | length')
echo "Prometheus metrics collected: $prometheus_querycount" >> "$REPORT_DIR/cc7-monitoring.txt"

# CC7.3 Organizational Policies
echo "=== CC7.3 Policies ===" > "$REPORT_DIR/cc7-policies.txt"
ls -la /etc/security/ >> "$REPORT_DIR/cc7-policies.txt"
cat /etc/security/limits.conf >> "$REPORT_DIR/cc7-policies.txt"

# CC7.4 Audit Logging
echo "=== CC7.4 Audit Logging ===" > "$REPORT_DIR/cc7-audit-logging.txt"
ausearch -ts 30-days-ago | wc -l >> "$REPORT_DIR/cc7-audit-logging.txt"
du -sh /var/log/audit/ >> "$REPORT_DIR/cc7-audit-logging.txt"

# C1: Availability
echo "=== C1: Availability ===" > "$REPORT_DIR/c1-availability.txt"
echo "Kubernetes cluster uptime:" >> "$REPORT_DIR/c1-availability.txt"
kubectl get nodes >> "$REPORT_DIR/c1-availability.txt"
echo "Node status:" >> "$REPORT_DIR/c1-availability.txt"
kubectl describe nodes >> "$REPORT_DIR/c1-availability.txt"

# S1: Security
echo "=== S1: Security ===" > "$REPORT_DIR/s1-security.txt"
echo "Vulnerability scan results:" >> "$REPORT_DIR/s1-security.txt"
curl -s "https://defectdojo:8000/api/v2/findings/" -H "Authorization: Token $TOKEN" | jq '.results | length' >> "$REPORT_DIR/s1-security.txt"

# Package evidence for auditors
tar czf "$REPORT_DIR/soc2-evidence-$(date +%Y-%m-%d).tar.gz" "$REPORT_DIR"
```

## 32.5 GDPR Compliance

### GDPR Core Principles

```
1. LAWFULNESS, FAIRNESS & TRANSPARENCY
   ├─ Legal basis for processing
   ├─ Privacy policy documented
   ├─ Consent obtained
   └─ Data processing agreement

2. PURPOSE LIMITATION
   ├─ Data collected for specified purpose
   ├─ No secondary processing without consent
   └─ Clear retention schedule

3. DATA MINIMIZATION
   ├─ Only collect needed data
   ├─ Delete after retention period
   └─ Implement data retention policy

4. ACCURACY
   ├─ Keep personal data accurate
   ├─ Allow subject corrections
   └─ Remove outdated data

5. STORAGE LIMITATION
   ├─ Retention: Max 3 years (unless legal requirement)
   ├─ Automated deletion process
   └─ Regular purge schedule

6. INTEGRITY & CONFIDENTIALITY
   ├─ Encryption (TLS + at rest)
```

## 32.7 Automated Evidence Collection

```bash
#!/bin/bash
# automated-compliance-report.sh

MONTH=$(date +%Y-%m)
REPORT_DIR="/compliance/reports/$MONTH"
mkdir -p "$REPORT_DIR"

echo "Collecting compliance evidence for $MONTH..."

# 1. Security Controls Evidence
echo "1. Security controls..."
kubectl get all -A -o json > "$REPORT_DIR/k8s-resources.json"
vault secrets list -format=json > "$REPORT_DIR/vault-secrets.json"
terraform show > "$REPORT_DIR/infrastructure.txt"

# 2. Vulnerability Status
echo "2. Vulnerability management..."
defectdojo-api findings list > "$REPORT_DIR/vulnerabilities.json"
trivy image --format json harbor.devsecops.com/myapp:latest > "$REPORT_DIR/container-scan.json"

# 3. Access Control Evidence
echo "3. Access control audit..."
kubectl get rbac -A > "$REPORT_DIR/rbac-audit.txt"
cat /var/log/auth.log | grep -E "sudo|authentication" > "$REPORT_DIR/access-audit.txt"

# 4. Network & Firewall
echo "4. Network configuration..."
ufw status numbered > "$REPORT_DIR/firewall-rules.txt"
route -n > "$REPORT_DIR/routing.txt"
netstat -tulpn > "$REPORT_DIR/listening-ports.txt"

# 5. Backup & Recovery
echo "5. Backup verification..."
ls -lah /mnt/backups/ > "$REPORT_DIR/backup-status.txt"
test-backup-restore.sh >> "$REPORT_DIR/recovery-test.txt"

# 6. Incident & Audit Logs
echo "6. Incident and audit logs..."
cat /var/log/audit/audit.log | tail -1000 > "$REPORT_DIR/audit-trail.txt"
journalctl -u kubelet -n 500 > "$REPORT_DIR/kubelet-logs.txt"

# 7. Patch Status
echo "7. System patch status..."
apt list --upgradable > "$REPORT_DIR/patches-available.txt"
dpkg -l > "$REPORT_DIR/installed-packages.txt"

# 8. Compliance Status
echo "8. Compliance status..."
openscap-scan.sh >> "$REPORT_DIR/cis-compliance.txt"
lynis audit system >> "$REPORT_DIR/security-audit.txt"

# 9. Create summary
cat > "$REPORT_DIR/COMPLIANCE-SUMMARY.txt" << SUMMARY
MONTHLY COMPLIANCE REPORT
Date: $(date)
Period: $MONTH

CONTROL STATUS:
- Security Controls: $(grep -c "PASSED" $REPORT_DIR/cis-compliance.txt) passed
- Vulnerabilities: $(jq '.count' $REPORT_DIR/vulnerabilities.json) open
- Access Reviews: Completed
- Patch Status: $(grep -c "upgradable" $REPORT_DIR/patches-available.txt) updates available
- Backup Tests: $(grep -c "success" $REPORT_DIR/recovery-test.txt) successful

EVIDENCE COLLECTED:
- Configuration files
- Audit logs
- Vulnerability assessments
- Access control reviews
- Backup verification
- Incident logs
- Patch status
- Security assessments

NEXT STEPS:
1. Review findings
2. Update controls as needed
3. Remediate vulnerabilities
4. Document changes
5. Notify stakeholders

COMPLIANCE OFFICER: _______________
DATE: $(date)
SUMMARY

# Package for auditors
tar czf "$REPORT_DIR/compliance-report-$MONTH.tar.gz" "$REPORT_DIR"

echo "Compliance report complete: $REPORT_DIR"
```
