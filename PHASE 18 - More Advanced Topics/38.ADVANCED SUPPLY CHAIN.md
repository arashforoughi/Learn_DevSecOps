## Software Bill of Materials (SBOM)

```bash
# Generate SBOM with Syft
syft alpine:latest -o spdx-json > sbom.json

SBOM Contents:
├─ Package name & version
├─ License information
├─ Dependency tree
├─ Known vulnerabilities
├─ Supplier information
└─ Creation timestamp

# Validate SBOM
sbom-utility validate -f sbom.json

# Sign SBOM with cosign
cosign sign-blob --key cosign.key sbom.json > sbom.json.sig
```

## SLSA Framework (Levels 1-4)

```
LEVEL 1: Provenance Only
├─ Build process documented
├─ Some version control
└─ No verification

LEVEL 2: Basic Integrity
├─ Hosted build platform
├─ Access controls
├─ Build logs retained
└─ Provenance generated

LEVEL 3: Advanced Integrity
├─ Security hardened build
├─ Secrets management
├─ Code review required
├─ Reproducible builds
└─ Artifact signing

LEVEL 4: Complete Supply Chain
├─ Multiple independent reviews
├─ Hermetic builds (no external inputs)
├─ Complete transparency
├─ Verified dependencies
└─ Secure distribution
```

## Artifact Signing & Verification

```bash
# Create signing key
cosign generate-key-pair

# Sign container image
cosign sign --key cosign.key harbor.devsecops.com/app:v1.0

# Verify signature
cosign verify --key cosign.pub harbor.devsecops.com/app:v1.0

# Sign attestation (build proof)
cosign attest --key cosign.key harbor.devsecops.com/app:v1.0

# Verify in Kubernetes
apiVersion: constraints.gatekeeper.sh/v1beta1
kind: K8sRequiredLabels
metadata:
  name: require-signed-images
spec:
  match:
    kinds:
    - apiGroups: [""]
      kinds: ["Pod"]
  parameters:
    labels: ["signedBy=cosign"]
```

## Container Image Security

```bash
# Scan image for vulnerabilities
trivy image --severity HIGH,CRITICAL harbor.devsecops.com/app:latest

# Sign image
cosign sign --key key.pem harbor.devsecops.com/app:latest

# Verify image signature
cosign verify --key key.pub harbor.devsecops.com/app:latest

# Create attestation
cosign attest \
  --predicate provenance.json \
  --key key.pem \
  harbor.devsecops.com/app:latest

# Enforce policy (Kyverno)
apiVersion: kyverno.io/v1
kind: ClusterPolicy
metadata:
  name: verify-signatures
spec:
  validationFailureAction: enforce
  rules:
  - name: check-signature
    match:
      resources:
        kinds:
        - Pod
    verifyImages:
    - imageReferences:
      - 'harbor.devsecops.com/*'
      attestations:
      - name: provenance
        predicateType: https://slsa.dev/provenance/v0.2
```
