## Cost Optimization & Security

```bash
# Right-sizing instances
aws ec2 describe-instances --query 'Reservations[*].Instances[*].[InstanceId,InstanceType,State.Name]'
gcloud compute instances list --format="table(name, machineType)"
az vm list --query "[].{name:name, vmSize:hardwareProfile.vmSize}"

# Spot/Preemptible instances
apiVersion: v1
kind: Pod
metadata:
  name: cost-optimized
spec:
  nodeSelector:
    cloud.google.com/gke-preemptible: "true"  # GCP
    aws.amazon.com/ec2/spot: "true"           # AWS
    azure.com/spot: "true"                     # Azure
  tolerations:
  - key: cloud.google.com/gke-preemptible
    operator: Equal
    value: "true"
    effect: NoSchedule

# Reserved instances for stable workloads
# Spot instances for batch/non-critical work
# On-demand for burst capacity
```

## Disaster Recovery Across Clouds

```
RTO: 1 hour
RPO: 15 minutes

ARCHITECTURE:
├─ Primary: AWS (active)
├─ Secondary: GCP (warm standby)
├─ Tertiary: Azure (cold standby)
└─ Data: Multi-region replication

ACTIVATION PROCEDURE:
1. Detect failure (< 2 min)
2. Update DNS to GCP (< 5 min)
3. Promote GCP workloads (< 15 min)
4. Verify functionality (< 30 min)
5. Notify stakeholders (< 5 min)
TOTAL RTO: < 57 minutes
```
