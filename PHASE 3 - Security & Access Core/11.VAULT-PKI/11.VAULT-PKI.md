## 11.1 PKI Concepts

|Concept|Explanation|Lab Implementation|
|---|---|---|
|**Root CA**|Self-signed, signs other CAs|Vault Root CA|
|**Intermediate CA**|Signed by Root, signs end-entity certs|Lab Intermediate CA (*.devsecops.com)|
|**End-Entity Cert**|Issued to services (HAProxy, etc.)|Certs for each service|
|**CSR**|Certificate Signing Request|Services request certs from Vault|
|**CRL**|Certificate Revocation List|List of revoked certs|
|**OCSP**|Online Certificate Status Protocol|Real-time cert validation|

### Why Vault PKI?

**Without Vault PKI:**

- ❌ Self-signed certs (browser warnings)
- ❌ Manual cert generation for each service
- ❌ Manual renewal (certificate expiration = service down)
- ❌ No audit (who created which cert, when?)

**With Vault PKI:**

- ✅ Trusted internal CA (no warnings)
- ✅ Automatic cert generation
- ✅ Automatic renewal (before expiration)
- ✅ Complete audit trail

## 11.2 PKI Setup on Vault

We already enabled PKI in Chapter 10. Now let's configure it fully.

### Step 1 — Create Root CA (Already done in Chapter 10)

If not done, create the root:

```bash
vm# export VAULT_ADDR="https://localhost:8200"
vm# export VAULT_TOKEN="s.xxxxx..."  # Your root token

# Generate root CA
vm# vault write -field=certificate pki/root/generate/internal \
    common_name="DevSecOps Lab Root CA" \
    ttl=87600h > /tmp/root_ca.crt

# Verify
vm# vault write pki/config/ca \
    pem_bundle=@/tmp/root_ca.crt
```

### Step 2 — Create Intermediate CA

Intermediate CA is signed by Root but used to issue end-entity certs:

```bash
# Enable intermediate PKI engine
vm# vault secrets enable -path=pki_int pki

# Set maximum certificate lifetime
vm# vault secrets tune -max-lease-ttl=43800h pki_int

# Generate intermediate CSR (certificate signing request)
vm# vault write -field=csr pki_int/intermediate/generate/csr \
    common_name="Lab Intermediate CA" \
    ou="DevSecOps Lab" \
    > /tmp/pki_intermediate.csr

# Sign the intermediate CSR with root CA
vm# vault write -field=certificate pki/root/sign-intermediate \
    csr=@/tmp/pki_intermediate.csr \
    common_name="Lab Intermediate CA" \
    ttl=43800h > /tmp/pki_intermediate.crt

# Set the signed certificate on the intermediate
vm# vault write pki_int/intermediate/set-signed \
    certificate=@/tmp/pki_intermediate.crt
```

### Step 3 — Create Certificate Roles

Roles define what certificates can be issued (domain, TTL, usage):

```bash
# Role for lab services (*.devsecops.com)
vm# vault write pki_int/roles/lab \
    allowed_domains="devsecops.com" \
    allow_subdomains=true \
    max_ttl="720h" \
    generate_lease=true

# Role for Kubernetes (*.cluster.local + *.default.svc)
vm# vault write pki_int/roles/k8s \
    allowed_domains="cluster.local" \
    allow_subdomains=true \
    max_ttl="720h"

# Role for services (specific list)
vm# vault write pki_int/roles/services \
    allowed_domains="devsecops.com" \
    allow_subdomains=false \
    allowed_other_sans="DNS:vault.devsecops.com,DNS:gitlab.devsecops.com,DNS:harbor.devsecops.com" \
    max_ttl="720h"
```

## 11.3 Issue Certificate to HAProxy

HAProxy needs a wildcard certificate for *.devsecops.com:

```bash
# Issue wildcard cert for HAProxy
vm# vault write -format=json pki_int/issue/lab \
    common_name="*.devsecops.com" \
    ttl="30d" > /tmp/haproxy_cert.json

# Extract certificate and key
vm# jq -r '.data.certificate' /tmp/haproxy_cert.json > /tmp/wildcard.crt
vm# jq -r '.data.private_key' /tmp/haproxy_cert.json > /tmp/wildcard.key

# Combine into single PEM file (HAProxy requirement)
vm# cat /tmp/wildcard.crt /tmp/wildcard.key > /tmp/wildcard.pem

# Copy to HAProxy
$ ssh sec-edge-01 'sudo mkdir -p /etc/haproxy/certs'
$ scp /tmp/wildcard.pem sec-edge-01:/tmp/
$ ssh sec-edge-01 'sudo mv /tmp/wildcard.pem /etc/haproxy/certs/devsecops.com.pem'
$ ssh sec-edge-01 'sudo chown haproxy:haproxy /etc/haproxy/certs/devsecops.com.pem'
$ ssh sec-edge-01 'sudo chmod 600 /etc/haproxy/certs/devsecops.com.pem'

# Reload HAProxy
$ ssh sec-edge-01 'sudo systemctl reload haproxy'
```

### Verify Certificate

## 11.4 Configure Certificate Auto-Renewal

Apps should refresh certificates before expiration (e.g., 7 days before 30-day cert expires).

### HAProxy Auto-Renewal Script

```bash
# Create renewal script
$ ssh sec-edge-01 'sudo tee /usr/local/bin/refresh-vault-cert.sh' << 'EOF'
#!/bin/bash
# Refresh certificate from Vault before expiration

set -euo pipefail

VAULT_ADDR="https://10.0.2.13:8200"
VAULT_TOKEN="${VAULT_TOKEN:-/var/lib/haproxy/.vault-token}"
CERT_PATH="/etc/haproxy/certs/devsecops.com.pem"
DAYS_BEFORE_EXPIRY=7

# Check if certificate expires within DAYS_BEFORE_EXPIRY
EXPIRY_DATE=$(openssl x509 -enddate -noout -in "$CERT_PATH" | cut -d= -f2)
EXPIRY_EPOCH=$(date -d "$EXPIRY_DATE" +%s)
NOW_EPOCH=$(date +%s)
DAYS_LEFT=$(( ($EXPIRY_EPOCH - $NOW_EPOCH) / 86400 ))

echo "Certificate expires in $DAYS_LEFT days"

if [ "$DAYS_LEFT" -le "$DAYS_BEFORE_EXPIRY" ]; then
    echo "Requesting new certificate from Vault..."
    
    # Request new certificate
    RESPONSE=$(curl -s -k \
        -H "X-Vault-Token: $(cat $VAULT_TOKEN)" \
        "$VAULT_ADDR/v1/pki_int/issue/lab" \
        -X POST \
        -d '{"common_name":"*.devsecops.com","ttl":"30d"}')
    
    # Extract certificate and key
    CERT=$(echo "$RESPONSE" | jq -r '.data.certificate')
    KEY=$(echo "$RESPONSE" | jq -r '.data.private_key')
    
    # Write to temporary file
    {
        echo "$CERT"
        echo "$KEY"
    } > "$CERT_PATH.new"
    
    # Verify new certificate is valid
    if openssl x509 -in "$CERT_PATH.new" -noout > /dev/null 2>&1; then
        # Replace old certificate
        mv "$CERT_PATH.new" "$CERT_PATH"
        
        # Reload HAProxy
        systemctl reload haproxy
        echo "Certificate renewed and HAProxy reloaded"
    else
        echo "ERROR: New certificate is invalid"
        rm "$CERT_PATH.new"
        exit 1
    fi
else
    echo "Certificate still valid, no renewal needed"
fi

EOF

sudo chmod +x /usr/local/bin/refresh-vault-cert.sh
```

### Cron Job for Auto-Renewal

```bash
# Create cron job to run daily
$ ssh sec-edge-01 'sudo tee /etc/cron.d/vault-cert-renewal' << 'EOF'
# Auto-refresh certificates from Vault
SHELL=/bin/bash
PATH=/usr/local/bin:/usr/bin:/bin

0 2 * * * root /usr/local/bin/refresh-vault-cert.sh >> /var/log/vault-cert-renewal.log 2>&1

EOF

# Verify cron job
$ ssh sec-edge-01 'sudo crontab -l | grep vault'
```

### Vault Certificate (for itself!)

```bash

vm# vault write -format=json pki_int/issue/lab \
    common_name="vault.devsecops.com" \
    ttl="30d" > /tmp/vault_cert.json

vm# jq -r '.data.certificate' /tmp/vault_cert.json | sudo tee /etc/vault/tls/vault.crt
vm# jq -r '.data.private_key' /tmp/vault_cert.json | sudo tee /etc/vault/tls/vault.key
vm# sudo chown vault:vault /etc/vault/tls/*
vm# sudo chmod 600 /etc/vault/tls/*
```

## 11.7 Audit: Certificate Issuance Logging

All certificate issuance is automatically logged in Vault audit logs:

```bash
# View recent certificate issuance
vm# sudo tail -100 /var/log/vault/audit.log | \
    grep "pki_int/issue" | jq -r '.request.path, .auth.metadata.user_id, .request.data'
```

Each certificate issuance shows:

- Who issued it (user/app token)
- When it was issued (timestamp)
- What certificate was issued (CN, SANs)
- Result (success/failure)

## 11.8 Monitoring Certificate Expiry

Create a monitoring script to alert before certificates expire:

```bash
$ cat > ~/lab/scripts/check-cert-expiry.sh << 'EOF'
#!/bin/bash
# Check certificate expiration dates

VAULT_ADDR="https://10.0.2.13:8200"
VAULT_TOKEN="${VAULT_TOKEN:-}"
DAYS_WARNING=14

echo "Checking certificate expiry..."

# Get list of certificates from Vault
CERTS=$(curl -s -k \
    -H "X-Vault-Token: $VAULT_TOKEN" \
    "$VAULT_ADDR/v1/pki_int/certs?list=true" | \
    jq -r '.data.keys[]' | sort -r | head -10)

for CERT_ID in $CERTS; do
    CERT_DATA=$(curl -s -k \
        -H "X-Vault-Token: $VAULT_TOKEN" \
        "$VAULT_ADDR/v1/pki_int/cert/$CERT_ID")
    
    EXPIRY=$(echo "$CERT_DATA" | jq -r '.data.expiration_time')
    CN=$(echo "$CERT_DATA" | jq -r '.data.certificate_details.common_name')
    
    EXPIRY_EPOCH=$(date -d "$EXPIRY" +%s)
    NOW_EPOCH=$(date +%s)
    DAYS_LEFT=$(( ($EXPIRY_EPOCH - $NOW_EPOCH) / 86400 ))
    
    if [ "$DAYS_LEFT" -le "$DAYS_WARNING" ]; then
        echo "⚠️  ALERT: $CN expires in $DAYS_LEFT days ($EXPIRY)"
    elif [ "$DAYS_LEFT" -le 0 ]; then
        echo "🚨 ERROR: $CN has expired! ($EXPIRY)"
    else
        echo "✅ OK: $CN expires in $DAYS_LEFT days"
    fi
done

EOF

chmod +x ~/lab/scripts/check-cert-expiry.sh
```

## 11.9 Integration with Ansible

Update your Ansible playbooks to fetch certificates from Vault:

```yaml
# roles/haproxy/tasks/main.yml
- name: Request certificate from Vault
  uri:
    url: "https://{{ vault_address }}/v1/pki_int/issue/lab"
    method: POST
    headers:
      X-Vault-Token: "{{ vault_token }}"
    body_format: json
    body:
      common_name: "*.devsecops.com"
      ttl: "30d"
  register: vault_cert
  
- name: Deploy certificate
  copy:
    content: |
      {{ vault_cert.json.data.certificate }}
      {{ vault_cert.json.data.private_key }}
    dest: /etc/haproxy/certs/devsecops.com.pem
    owner: haproxy
    group: haproxy
    mode: '0600'
  notify: reload haproxy
```

## 11.10 Troubleshooting

### Problem: "Certificate validation failed"

The certificate issuer is not trusted:

```bash
# Copy Vault's root CA to your system
vm# cp /tmp/root_ca.crt /usr/local/share/ca-certificates/vault-ca.crt
vm# sudo update-ca-certificates

# Or skip verification (for testing):
export VAULT_SKIP_VERIFY=true
```

### Problem: Certificate renewal fails

Check Vault connectivity and authentication:

```bash
# Test Vault access
curl -k -H "X-Vault-Token: $VAULT_TOKEN" \
    https://vault.devsecops.com:8200/v1/pki_int/roles/lab

# Check audit logs for errors
sudo tail -50 /var/log/vault/audit.log | grep -i error
```

### Problem: Certificate has wrong CN or SANs

Certificate was issued with incorrect parameters:

```bash
# Check what was issued
openssl x509 -in /etc/haproxy/certs/devsecops.com.pem -text -noout | \
    grep -A5 "Subject Alternative Name"

# Revoke the bad certificate
vm# vault write pki_int/revoke \
    serial_number="01:23:45:67:89:ab:cd:ef"

# Re-issue with correct parameters
```

## 11.11 Validation Script — Chapter 11

```bash
#!/bin/bash
# ~/lab/scripts/validate-chapter-11.sh

set -euo pipefail

VAULT_IP="10.0.2.13"
HAPROXY_IP="10.0.2.12"
PASS=0
FAIL=0

echo "============================================="
echo " Chapter 11 Validation — Vault PKI          "
echo "============================================="

echo ""
echo "--- Vault PKI Engine ---"

if ssh sec-vault-01 'vault secrets list | grep -q "pki_int"' 2>/dev/null; then
    echo "  ✅ PASS: Intermediate PKI engine enabled"
    ((PASS++))
else
    echo "  ❌ FAIL: Intermediate PKI not found"
    ((FAIL++))
fi

echo ""
echo "--- Certificate Roles ---"

if ssh sec-vault-01 'vault list pki_int/roles | grep -q "lab"' 2>/dev/null; then
    echo "  ✅ PASS: Lab certificate role exists"
    ((PASS++))
else
    echo "  ❌ FAIL: Lab certificate role missing"
    ((FAIL++))
fi

echo ""
echo "--- HAProxy Certificate ---"

if ssh sec-edge-01 'test -f /etc/haproxy/certs/devsecops.com.pem' 2>/dev/null; then
    echo "  ✅ PASS: HAProxy certificate exists"
    ((PASS++))
else
    echo "  ❌ FAIL: HAProxy certificate missing"
    ((FAIL++))
fi

echo ""
echo "--- Certificate Validity ---"

if ssh sec-edge-01 'openssl x509 -in /etc/haproxy/certs/devsecops.com.pem -noout -checkend 0' 2>/dev/null; then
    echo "  ✅ PASS: HAProxy certificate is valid"
    ((PASS++))
else
    echo "  ❌ FAIL: HAProxy certificate is invalid/expired"
    ((FAIL++))
fi

echo ""
echo "--- Certificate Issuer ---"

issuer=$(ssh sec-edge-01 'openssl x509 -in /etc/haproxy/certs/devsecops.com.pem -noout -issuer' 2>/dev/null || echo "")
if echo "$issuer" | grep -q "Lab Intermediate CA"; then
    echo "  ✅ PASS: Certificate issued by Vault PKI"
    ((PASS++))
else
    echo "  ⚠️  WARNING: Certificate issuer unexpected"
    ((PASS++))
fi

echo ""
echo "--- Results ---"
echo "  Passed: ${PASS}"
echo "  Failed: ${FAIL}"

if [ "$FAIL" -eq 0 ]; then
    echo ""
    echo "🎉 Vault PKI is operational!"
    echo "   All services now use trusted certificates."
else
    echo ""
    echo "⚠️  ${FAIL} check(s) failed."
    exit 1
fi

```
