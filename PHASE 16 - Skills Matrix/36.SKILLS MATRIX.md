# Chapter 36 — Skills Assessment Matrix
## DevSecOps Lab Book — Competency Framework

---

## Skills by Role

### Infrastructure Engineer
```
REQUIRED SKILLS:
├─ Linux administration: Expert
├─ Networking (TCP/IP, DNS): Advanced
├─ Virtualization (KVM/QEMU): Advanced
├─ Infrastructure as Code: Expert
├─ Container fundamentals: Advanced
└─ Kubernetes: Intermediate

ASSESSMENT:
✓ Deploy 3-node K8s cluster in < 2 hours
✓ Configure network segmentation with VLANs
✓ Implement disaster recovery procedure
✓ Scale infrastructure using IaC
✓ Troubleshoot etcd cluster issues
```

### Security Engineer
```
REQUIRED SKILLS:
├─ Linux security hardening: Expert
├─ Cryptography fundamentals: Advanced
├─ Network security: Advanced
├─ Incident response: Expert
├─ Compliance frameworks: Advanced
└─ Threat analysis: Intermediate

ASSESSMENT:
✓ Apply CIS benchmarks to systems
✓ Detect intrusions using IDS/IPS
✓ Respond to security incident in < 1 hour
✓ Perform forensic analysis
✓ Design secure architecture
```

### DevOps Engineer
```
REQUIRED SKILLS:
├─ CI/CD pipelines: Expert
├─ Container orchestration: Advanced
├─ Monitoring/observability: Advanced
├─ Automation/scripting: Expert
├─ Release management: Advanced
└─ Performance optimization: Intermediate

ASSESSMENT:
✓ Deploy application via GitOps (< 5 min)
✓ Implement auto-scaling policies
✓ Monitor systems with ELK/Prometheus
✓ Respond to performance issues
✓ Automate common operational tasks
```

### Application Developer
```
REQUIRED SKILLS:
├─ Secure coding: Advanced
├─ Container basics: Intermediate
├─ API design: Advanced
├─ Testing (unit/integration): Advanced
├─ Kubernetes deployments: Intermediate
└─ Security testing: Intermediate

ASSESSMENT:
✓ Write secure code (pass SAST)
✓ Create Docker image (pass scanning)
✓ Deploy Helm chart to K8s
✓ Write security tests
✓ Fix vulnerabilities < 24 hours (critical)
```

## Learning Paths

```
PATH 1: Infrastructure → Security
Month 1-2: Linux & networking
Month 3-4: Infrastructure as Code
Month 5-6: Security fundamentals
Month 7-8: Advanced security
Result: DevSecOps Architect

PATH 2: Developer → DevSecOps
Month 1-2: Secure coding
Month 3-4: Container security
Month 5-6: CI/CD security
Month 7-8: Operations
Result: Full-stack DevSecOps Engineer

PATH 3: Security → DevOps
Month 1-2: Security fundamentals
Month 3-4: Linux hardening
Month 5-6: Infrastructure
Month 7-8: CI/CD & containers
Result: Security-focused DevOps
```
