## Zero Trust Principles

```
Traditional: Trust the network (perimeter security)
❌ Problems:
  ├─ Breach inside perimeter = full access
  ├─ Lateral movement easy
  ├─ No micro-segmentation
  └─ Difficult to detect internal threats

Zero Trust: Trust nobody, verify everything
✅ Solutions:
  ├─ Every access authenticated & authorized
  ├─ Encryption everywhere (in transit & rest)
  ├─ Continuous monitoring
  ├─ Micro-segmentation
  └─ Least privilege access
```

## Implementation Layers

```
1. IDENTITY & ACCESS
   ├─ Multi-factor authentication (MFA) everywhere
   ├─ Continuous device posture checking
   ├─ Risk-based access decisions
   └─ Teleport for all SSH access

2. DATA
   ├─ Encrypt in transit (TLS everywhere)
   ├─ Encrypt at rest (Vault encryption)
   ├─ Data classification
   └─ DLP (Data Loss Prevention)

3. NETWORK
   ├─ Microsegmentation (per-application isolation)
   ├─ Network policies enforced everywhere
   ├─ Encrypted service-to-service (mTLS)
   └─ No implicit trust between services

4. DEVICES
   ├─ Hardware security modules (HSM)
   ├─ Full disk encryption
   ├─ Endpoint Detection & Response (EDR)
   └─ Vulnerability scanning

5. WORKLOADS
   ├─ Container security scanning
   ├─ Immutable infrastructure
   ├─ Runtime security enforcement
   └─ Behavioral analysis
```

## Kubernetes Zero Trust

```yaml
# Complete zero trust setup

# 1. Pod Security Standards
apiVersion: policy/v1beta1
kind: PodSecurityPolicy
metadata:
  name: restricted
spec:
  privileged: false
  allowPrivilegeEscalation: false
  requiredDropCapabilities: ["ALL"]
  volumes: ["configMap", "emptyDir", "projected", "secret", "downwardAPI", "persistentVolumeClaim"]
  runAsUser:
    rule: "MustRunAsNonRoot"
  seLinux:
    rule: "MustRunAs"
  supplementalGroups:
    rule: "RunAsAny"
  fsGroup:
    rule: "RunAsAny"
  readOnlyRootFilesystem: true

# 2. Network Policy: Default Deny
apiVersion: networking.k8s.io/v1
kind: NetworkPolicy
metadata:
  name: default-deny
spec:
  podSelector: {}
  policyTypes:
  - Ingress
  - Egress

# 3. RBAC: Least Privilege
apiVersion: rbac.authorization.k8s.io/v1
kind: Role
metadata:
  name: app-reader
rules:
- apiGroups: [""]
  resources: ["pods"]
  verbs: ["get", "list"]

# 4. Istio Authorization
apiVersion: security.istio.io/v1beta1
kind: AuthorizationPolicy
metadata:
  name: app-authz
spec:
  rules:
  - from:
    - source:
        principals: ["cluster.local/ns/default/sa/app"]
    to:
    - operation:
        methods: ["GET"]
        paths: ["/api/v1/users"]

# 5. Secrets Encryption
apiVersion: apiserver.config.k8s.io/v1
kind: EncryptionConfiguration
resources:
- resources:
  - secrets
  providers:
  - aescbc:
      keys:
      - name: key1
        secret: [32-byte-base64-key]
  - identity: {}
```
