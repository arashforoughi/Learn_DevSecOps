## Rapid Deployment (30 Minutes)

```bash
# 1. Clone repository
git clone https://github.com/devsecops/lab ~/lab && cd ~/lab

# 2. Initialize Terraform
cd opentofu && terraform init

# 3. Deploy infrastructure
terraform apply -auto-approve

# 4. Configure with Ansible
cd ../ansible && ansible-playbook site.yml

# 5. Validate
kubectl get nodes
```

## Phase-by-Phase Deployment

### Phase 1: Foundation (DNS, Identity, HTTPS)
- Time: 8-10 hours
- VMs: 7 (DNS, Identity, Load Balancer, Proxy, Auth, Vault, VCS)
- Key: All certificates and networking must work first

### Phase 2: Automation (IaC)
- Time: 6-8 hours
- Tools: Packer, Terraform, Ansible
- Deliverable: 30-minute full lab deployment

### Phase 3: Security (Secrets & Access)
- Time: 8-10 hours
- Focus: Vault + Teleport integration
- Validation: All access must be auditable

### Phase 4: CI/CD (Supply Chain)
- Time: 12-14 hours
- Most complex phase
- Includes: GitLab, scanning, compliance

### Phase 5: Advanced (HA, DR, Performance)
- Time: 8-10 hours
- High availability etcd, clustering
- Disaster recovery procedures

### Phase 6-13: Container & Advanced
- Time: 40-50 hours
- Kubernetes, Helm, Istio, GitOps, monitoring
- Advanced patterns and compliance

## Customization

```bash
# Change network: sed -i 's/10.0.2.0\/24/YOUR_CIDR/g' *.tf
# Change domain: sed -i 's/devsecops.com/YOUR_DOMAIN/g' *.yaml
# Scale workers: Edit terraform variables
# Adjust resources: Modify CPU/RAM/disk in IaC
```

## Troubleshooting

```bash
VMs not starting: virsh list --all
Network issues: virsh net-list
DNS problems: nslookup devsecops.com 10.0.2.10
K8s not ready: kubectl describe nodes
Terraform errors: terraform state list | terraform show
```

## Recovery

```bash
# Backup VMs
virsh dumpxml cp-01 > /mnt/backups/cp-01.xml

# Backup etcd
ETCDCTL_API=3 etcdctl snapshot save /mnt/backups/etcd.db

# Backup Vault
vault write sys/storage/raft/snapshot file=@vault-snapshot

# Test recovery regularly
```
