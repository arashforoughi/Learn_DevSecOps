## 9.1 Why Ansible Exists

After Chapter 08 (OpenTofu), we have 12 VMs running. But they're **blank**.

Manual approach (Chapter 01–06):

1. SSH into each VM
2. Manually install packages
3. Copy config files
4. Start services
5. Hope nothing was missed

Problem: **Not repeatable.** If a VM fails or you need 20 VMs instead of 12, you're doing all this again manually.

🏗️ **Analogy:** OpenTofu is like hiring a contractor to build 12 empty houses. Ansible is like hiring a crew to furnish each house identically (furniture, plumbing, electrical, etc.) based on a blueprint.

## 9.2 Ansible vs Configuration Management

|Tool|Approach|Learning Curve|Agent|
|---|---|---|---|
|**Ansible**|Declarative, simple|Easy|Agentless (SSH)|
|**Chef**|Imperative, powerful|Hard|Agent required|
|**Puppet**|Declarative, complex|Hard|Agent required|
|**SaltStack**|Imperative, fast|Medium|Agent required|

**For this lab:** Ansible is ideal. It's simple (YAML), agentless (just SSH), and perfect for configuration management.

## 9.5 Ansible Configuration

```bash
$ cat > ~/lab/ansible/devsecops-lab/ansible.cfg << 'EOF'
[defaults]
# Inventory file (list of VMs to manage)
inventory = ./inventory.ini

# User to connect as
remote_user = ubuntu

# SSH settings
host_key_checking = False
timeout = 30

# Parallel execution (faster)
forks = 10

# Logging
log_path = ./ansible.log
verbosity = 1

# Avoid sudo asking for password
[privilege_escalation]
become = True
become_method = sudo
become_user = root
become_ask_pass = False

EOF
```

## 9.7 Common Role (Applied to All VMs)

Create a "common" role that all VMs inherit:

```bash
mkdir -p ~/lab/ansible/devsecops-lab/roles/common/{tasks,templates,files}
```

### Common Tasks

```bash
$ cat > ~/lab/ansible/devsecops-lab/roles/common/tasks/main.yml << 'EOF'
---
# Common configuration for all VMs

- name: Update package cache
  apt:
    update_cache: yes
    cache_valid_time: 3600

- name: Install common packages
  apt:
    name:
      - curl
      - wget
      - git
      - vim
      - htop
      - net-tools
      - dnsutils
      - tcpdump
      - nmap
      - ufw
      - fail2ban
      - auditd
      - chrony
      - rsyslog
      - ca-certificates
      - gnupg
      - jq
      - python3
      - python3-pip
    state: present

- name: Set timezone to UTC
  timezone:
    name: UTC

- name: Configure UFW firewall
  ufw:
    state: enabled
    default: deny
    direction: "{{ item.direction }}"
  loop:
    - { direction: 'incoming' }
    - { direction: 'outgoing' }

- name: Allow SSH
  ufw:
    rule: allow
    port: '22'
    proto: tcp

- name: Configure SSH hardening
  copy:
    content: |
      PermitRootLogin no
      PasswordAuthentication yes
      PermitEmptyPasswords no
      Protocol 2
      ClientAliveInterval 300
      ClientAliveCountMax 2
      MaxAuthTries 3
      X11Forwarding no
      LogLevel VERBOSE
    dest: /etc/ssh/sshd_config.d/hardening.conf
    owner: root
    group: root
    mode: '0644'
  notify: restart ssh

- name: Configure fail2ban
  copy:
    content: |
      [DEFAULT]
      bantime = 3600
      findtime = 600
      maxretry = 5
      
      [sshd]
      enabled = true
    dest: /etc/fail2ban/jail.local
    owner: root
    group: root
    mode: '0644'
  notify: restart fail2ban

- name: Enable and start fail2ban
  systemd:
    name: fail2ban
    enabled: yes
    state: started

- name: Enable and start chrony (time sync)
  systemd:
    name: chrony
    enabled: yes
    state: started

- name: Enable auditd
  systemd:
    name: auditd
    enabled: yes
    state: started

handlers:
  - name: restart ssh
    systemd:
      name: ssh
      state: restarted

  - name: restart fail2ban
    systemd:
      name: fail2ban
      state: restarted

EOF
```

## 9.8 Specific Roles (BIND9 Example)

Create a role for BIND9:

```bash
mkdir -p ~/lab/ansible/devsecops-lab/roles/bind9/{tasks,templates,files}
```

### BIND9 Tasks

```bash
$ cat > ~/lab/ansible/devsecops-lab/roles/bind9/tasks/main.yml << 'EOF'
---
# Install and configure BIND9 DNS

- name: Install BIND9
  apt:
    name:
      - bind9
      - bind9utils
      - bind9-doc
      - dnsutils
    state: present

- name: Deploy named.conf.options
  template:
    src: named.conf.options.j2
    dest: /etc/bind/named.conf.options
    owner: root
    group: bind
    mode: '0640'
  notify: reload bind9

- name: Deploy named.conf.local
  template:
    src: named.conf.local.j2
    dest: /etc/bind/named.conf.local
    owner: root
    group: bind
    mode: '0640'
  notify: reload bind9

- name: Create zones directory
  file:
    path: /etc/bind/zones
    owner: root
    group: bind
    mode: '0750'
    state: directory

- name: Deploy zone files
  template:
    src: "{{ item.src }}"
    dest: "/etc/bind/zones/{{ item.dest }}"
    owner: root
    group: bind
    mode: '0640'
  loop:
    - { src: "db.devsecops.com.internal.j2", dest: "db.devsecops.com.internal" }
    - { src: "db.devsecops.com.external.j2", dest: "db.devsecops.com.external" }
    - { src: "db.10.0.2.j2", dest: "db.10.0.2" }
  notify: reload bind9

- name: Validate BIND9 configuration
  command: named-checkconf
  check_mode: no

- name: Enable and start BIND9
  systemd:
    name: bind9
    enabled: yes
    state: started

- name: Allow DNS in UFW
  ufw:
    rule: allow
    port: '53'
    proto: "{{ item }}"
    from_ip: 10.0.2.0/24
  loop:
    - tcp
    - udp

handlers:
  - name: reload bind9
    systemd:
      name: bind9
      state: reloaded

EOF
```

### BIND9 Templates

Create Jinja2 templates for BIND9 config files:

```bash
$ cat > ~/lab/ansible/devsecops-lab/roles/bind9/templates/named.conf.options.j2 << 'EOF'
options {
    directory "/var/cache/bind";
    forwarders {
        1.1.1.1;
        8.8.8.8;
    };
    forward only;
    dnssec-validation auto;
    listen-on {
        127.0.0.1;
        10.0.2.10;
    };
    listen-on-v6 { none; };
    allow-query { localnets; localhost; };
    allow-recursion { localnets; localhost; };
    allow-transfer { none; };
    recursion yes;
    rate-limit {
        responses-per-second 10;
        window 5;
    };
    max-cache-size 64m;
    version "DNS Server";
};
EOF
```

## 9.12 Idempotent Playbooks

Ansible playbooks are **idempotent** — safe to run multiple times:

```bash
# Run the same playbook again
$ ansible-playbook playbooks/site.yml
```

```
# Second run output (should show "ok" but few "changed"):
→ sec-dns-01: ok=10 changed=0 unreachable=0 failed=0
→ sec-idm-01: ok=15 changed=0 unreachable=0 failed=0
→ ... (everything is in desired state, no changes needed)
```

This is the power of Ansible: **describe what you want, not how to get there**.

## 9.13 Advanced Ansible Patterns

### Run Only Certain Roles

```bash
# Configure only DNS
$ ansible-playbook -t dns playbooks/site.yml

# Configure only identity
$ ansible-playbook -t identity playbooks/site.yml
```

### Run Only Certain Hosts

```bash
# Configure only DNS VMs
$ ansible-playbook -l dns playbooks/site.yml

# Configure only edge servers
$ ansible-playbook -l edge playbooks/site.yml
```

### Run with Extra Variables

```bash
# Override variables at runtime
$ ansible-playbook -e "dns_server=8.8.8.8" playbooks/site.yml
```

### Parallel Execution

```bash
# Run on multiple hosts at once (default: 5)
$ ansible-playbook -f 10 playbooks/site.yml  # Use 10 parallel forks
```

## 9.14 Validation Script — Chapter 09

```bash
#!/bin/bash
# ~/lab/scripts/validate-chapter-09.sh

set -euo pipefail

ANSIBLE_DIR="$HOME/lab/ansible/devsecops-lab"
PASS=0
FAIL=0

echo "============================================="
echo " Chapter 09 Validation — Ansible Config      "
echo "============================================="

echo ""
echo "--- Ansible Installation ---"

if command -v ansible &> /dev/null; then
    version=$(ansible --version | head -1)
    echo "  ✅ PASS: Ansible installed ($version)"
    ((PASS++))
else
    echo "  ❌ FAIL: Ansible not found"
    ((FAIL++))
fi

echo ""
echo "--- Project Structure ---"

for dir in roles playbooks templates files; do
    if [ -d "$ANSIBLE_DIR/$dir" ]; then
        echo "  ✅ PASS: $dir directory exists"
        ((PASS++))
    else
        echo "  ❌ FAIL: $dir directory missing"
        ((FAIL++))
    fi
done

echo ""
echo "--- Key Files ---"

for file in ansible.cfg inventory.ini; do
    if [ -f "$ANSIBLE_DIR/$file" ]; then
        echo "  ✅ PASS: $file exists"
        ((PASS++))
    else
        echo "  ❌ FAIL: $file missing"
        ((FAIL++))
    fi
done

echo ""
echo "--- Playbook Syntax ---"

if cd "$ANSIBLE_DIR" && ansible-playbook --syntax-check playbooks/site.yml > /dev/null 2>&1; then
    echo "  ✅ PASS: Playbook syntax is valid"
    ((PASS++))
else
    echo "  ❌ FAIL: Playbook syntax is invalid"
    ((FAIL++))
fi

echo ""
echo "--- Ansible Connectivity ---"

if cd "$ANSIBLE_DIR" && ansible all -i inventory.ini -m ping 2>/dev/null | grep -q "SUCCESS"; then
    echo "  ✅ PASS: Ansible can reach at least one host"
    ((PASS++))
else
    echo "  ⚠️  WARNING: Ansible connectivity failed (VMs may not be running)"
    ((PASS++))
fi

echo ""
echo "--- Results ---"
echo "  Passed: ${PASS}"
echo "  Failed: ${FAIL}"

if [ "$FAIL" -eq 0 ]; then
    echo ""
    echo "🎉 Ansible is ready!"
    echo "   Next: cd $ANSIBLE_DIR && ansible-playbook playbooks/site.yml"
else
    echo ""
    echo "⚠️  ${FAIL} check(s) failed."
    exit 1
fi

```
