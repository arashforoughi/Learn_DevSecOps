## 8.1 Why Infrastructure as Code Exists

Without IaC, infrastructure is **snowflake** — custom, undocumented, hard to replicate.

### The Problem (Manual Approach)

You need to document:

- "Which VMs exist?"
- "What are their IPs?"
- "What firewall rules apply?"
- "How do they connect?"

Someone makes a manual change (wrong). You have to audit the running system to find it. Disaster recovery means "rebuild from memory."

### The Solution (IaC)

Everything is code. You can:

- Read the code: "Here's exactly what infrastructure exists"
- Review changes: "What changed?" (git diff)
- Test changes: "What will terraform do?" (terraform plan)
- Audit history: "Who made this change when?" (git log)
- Recover quickly: "Rebuild from code in 1 hour"

🏗️ **Analogy:** Think of IaC like a software codebase:

- **Without IaC:** Infrastructure is like a closed-source binary (can't inspect, hard to modify)
- **With IaC:** Infrastructure is like open-source code (anyone can read, review, modify, audit)

## 8.2 OpenTofu vs Terraform

|Feature|Terraform|OpenTofu|
|---|---|---|
|**Cost**|Free, but licensed|Open-source (MPL 2.0)|
|**Language**|HCL|Same HCL (compatible)|
|**Providers**|Hashicorp maintained|Community maintained|
|**State Lock**|Excellent|Excellent|
|**Security**|Good|Good|
|**Governance**|Vendor-backed|Community-driven|

**For this lab:** OpenTofu and Terraform are interchangeable. We use OpenTofu to avoid vendor lock-in.

## 8.5 Provider Configuration

The provider tells OpenTofu what to manage (in our case, KVM via libvirt).

### Step 1 — Install libvirt Provider

```bash
# The libvirt provider allows OpenTofu to manage KVM VMs
$ mkdir -p ~/.terraform.plugins/registry.terraform.io/dmacvicar/libvirt/0.7.1/linux_amd64

# Download the plugin
$ cd ~/.terraform.plugins/registry.terraform.io/dmacvicar/libvirt/0.7.1/linux_amd64
$ wget https://github.com/dmacvicar/terraform-provider-libvirt/releases/download/v0.7.1/terraform-provider-libvirt-0.7.1+git.1710788881.c10f5e72-linux-amd64.zip
$ unzip terraform-provider-libvirt-0.7.1+git.1710788881.c10f5e72-linux-amd64.zip
$ chmod +x terraform-provider-libvirt
```

### Step 2 — Create providers.tf

```bash
$ cat > ~/lab/opentofu/devsecops-lab/providers.tf << 'EOF'
#
# OpenTofu Provider Configuration
#

terraform {
  required_version = ">= 1.0"
  
  required_providers {
    libvirt = {
      source  = "dmacvicar/libvirt"
      version = "~> 0.7.1"
    }
  }
}

provider "libvirt" {
  # Connect to the system libvirt daemon
  # Uses SSH: qemu:///system (local KVM)
  uri = "qemu:///system"
}

EOF
```

## 8.8 Define the VMs

```bash
$ cat > ~/lab/opentofu/devsecops-lab/vms.tf << 'EOF'
#
# OpenTofu VM Configuration
# Defines all 12 VMs for the DevSecOps lab
#

# Data source: Fetch the base image
data "libvirt_image" "ubuntu-22.04" {
  name = "ubuntu-22.04-packer"
  pool = "default"
}

# Create a volume for each VM
resource "libvirt_volume" "vm_disk" {
  for_each        = var.vms
  name            = "${each.key}.qcow2"
  pool            = "default"
  base_volume_id  = data.libvirt_image.ubuntu-22.04.id
  size            = each.value.disk_gb * 1024 * 1024 * 1024  # Convert GB to bytes
}

# Network interface for each VM
resource "libvirt_network_interface" "vm_net" {
  for_each = var.vms
  
  network_id     = libvirt_network.devsecops.id
  addresses      = [each.value.ip]
  mac            = "52:54:00:12:34:${format("%02x", index(keys(var.vms), each.key))}"
  hostname       = "${each.key}.${var.domain}"
  wait_for_lease = false
}

# Domain (VM) definition
resource "libvirt_domain" "vm" {
  for_each   = var.vms
  name       = each.key
  memory     = each.value.memory
  vcpu       = each.value.vcpu
  autostart  = true

  # Console access via serial port
  console {
    type           = "pty"
    target_port    = "0"
    target_type    = "serial"
  }

  # Primary disk
  disk {
    volume_id = libvirt_volume.vm_disk[each.key].id
  }

  # Network interface
  network_interface {
    network_id     = libvirt_network.devsecops.id
    addresses      = [each.value.ip]
    mac            = "52:54:00:12:34:${format("%02x", index(keys(var.vms), each.key))}"
    hostname       = "${each.key}.${var.domain}"
  }

  # CPU configuration (use host CPU for best performance)
  cpu {
    mode = "host-passthrough"
  }

  # QEMU arguments for optimization
  qemu_type = "system"
  machine   = "pc"

  depends_on = [
    libvirt_network.devsecops,
    libvirt_volume.vm_disk,
  ]
}

EOF
```

## 8.14 Advanced: Environments

For multiple environments (dev, staging, prod), use separate tfvars files:

```bash
# Create environment-specific configs
$ cat > environments/dev.tfvars << 'EOF'
environment = "dev"
network_cidr = "10.0.2.0/24"
EOF

$ cat > environments/prod.tfvars << 'EOF'
environment = "prod"
network_cidr = "10.1.0.0/24"  # Different network for prod
EOF
```

Then deploy to different environments:

```bash
$ tofu apply -var-file=environments/dev.tfvars
$ tofu apply -var-file=environments/prod.tfvars
```

## 8.17 State Management

OpenTofu tracks state in `terraform.tfstate`:

```bash
# Never edit tfstate directly!
# Always use tofu commands

# View current state
$ tofu show

# Show specific resource
$ tofu state show libvirt_domain.vm["sec-dns-01"]

# List all resources
$ tofu state list

# Move resource (if you rename it)
$ tofu state mv libvirt_domain.vm["old-name"] libvirt_domain.vm["new-name"]

# Remove resource from state (careful!)
$ tofu state rm libvirt_domain.vm["to-delete"]
```

## 8.19 Validation Script — Chapter 08

```bash
#!/bin/bash
# ~/lab/scripts/validate-chapter-08.sh

set -euo pipefail

TOFU_DIR="$HOME/lab/opentofu/devsecops-lab"
PASS=0
FAIL=0

echo "============================================="
echo " Chapter 08 Validation — OpenTofu IaC       "
echo "============================================="

echo ""
echo "--- OpenTofu Installation ---"

if command -v tofu &> /dev/null; then
    version=$(tofu version | head -1)
    echo "  ✅ PASS: OpenTofu installed ($version)"
    ((PASS++))
else
    echo "  ❌ FAIL: OpenTofu not found"
    ((FAIL++))
fi

echo ""
echo "--- Configuration Files ---"

for file in variables.tf providers.tf vms.tf outputs.tf terraform.tfvars; do
    if [ -f "$TOFU_DIR/$file" ]; then
        echo "  ✅ PASS: $file exists"
        ((PASS++))
    else
        echo "  ❌ FAIL: $file not found"
        ((FAIL++))
    fi
done

echo ""
echo "--- Configuration Validation ---"

if cd "$TOFU_DIR" && tofu validate > /dev/null 2>&1; then
    echo "  ✅ PASS: Configuration is valid"
    ((PASS++))
else
    echo "  ❌ FAIL: Configuration validation failed"
    ((FAIL++))
fi

echo ""
echo "--- Terraform State ---"

if [ -f "$TOFU_DIR/terraform.tfstate" ]; then
    vm_count=$(tofu state list 2>/dev/null | grep "libvirt_domain.vm" | wc -l || echo "0")
    echo "  ✅ PASS: State file exists ($vm_count VMs deployed)"
    ((PASS++))
else
    echo "  ℹ️  INFO: No state file (run 'tofu apply' to deploy)"
fi

echo ""
echo "--- VMs Running (if deployed) ---"

if command -v virsh &> /dev/null; then
    vm_count=$(virsh list --name | grep -E "sec-|k8s-" | wc -l || echo "0")
    if [ "$vm_count" -ge 12 ]; then
        echo "  ✅ PASS: All 12 VMs running"
        ((PASS++))
    elif [ "$vm_count" -gt 0 ]; then
        echo "  ⚠️  WARNING: Only $vm_count VMs running (expected 12)"
        ((PASS++))
    else
        echo "  ℹ️  INFO: No VMs running yet (run 'tofu apply')"
    fi
fi

echo ""
echo "--- Results ---"
echo "  Passed: ${PASS}"
echo "  Failed: ${FAIL}"

if [ "$FAIL" -eq 0 ]; then
    echo ""
    echo "🎉 OpenTofu is ready!"
    echo "   Next: cd $TOFU_DIR && tofu plan"
else
    echo ""
    echo "⚠️  ${FAIL} check(s) failed."
    exit 1
fi

```

## 8.20 Troubleshooting

### Problem: "No such file or directory" for image

The Packer image doesn't exist.

```bash
# Build it first (Chapter 07)
$ cd ~/lab/packer/ubuntu-22.04
$ packer build .

# Verify it exists
$ ls -la /var/lib/libvirt/images/ubuntu-22.04-packer.qcow2
```

### Problem: "Plugin error: permission denied"

libvirt provider can't connect to KVM.

```bash
# Add your user to the libvirt group
$ sudo usermod -aG libvirt $USER
$ newgrp libvirt

# Or run as root
$ sudo tofu apply
```

### Problem: "Error creating domain: Name already exists"

VM already exists (maybe from Chapter 01).

```bash
# Delete the old VM
$ virsh destroy sec-dns-01
$ virsh undefine sec-dns-01
$ rm /var/lib/libvirt/images/sec-dns-01.qcow2

# Then apply OpenTofu
$ tofu apply
```

### Problem: Apply hangs or takes very long

VMs are starting in parallel (normal). Give it time (5–10 minutes for 12 VMs).

```bash
# Monitor progress
$ virsh list --all
# Watch the State column (should show "running")
```
